# Milan Rachhadiya — Portfolio Website

Responsive personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace the placeholder GitHub and LinkedIn URLs with your real profile URLs.
2. Update project links to the actual repositories (do not leave links pointing to the generic GitHub homepage).
3. Check the resume in `assets/resume.pdf`.
4. Commit and push the files to a public GitHub repository named `Milan_PortfolioWebsite`.
5. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The contact form uses `mailto:` and therefore opens the visitor's email application; it does not send or store messages on a server.
